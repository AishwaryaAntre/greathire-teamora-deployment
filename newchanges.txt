1. Major new feature: Dark Mode

This is the headline change, touching almost every file:

New file: frontend/src/lib/ThemeContext.jsx — a full theme provider with useTheme() hook, localStorage persistence, and syncing with the OS's prefers-color-scheme.
main.jsx — app is now wrapped in <ThemeProvider>.
index.html — added an inline pre-hydration script that sets the dark class before React loads, so there's no light-mode flash on page load.
index.css — added a full .dark { ... } CSS variable palette (background, foreground, card, primary, border, etc.).
Nearly every component/page (DashboardTopBar, EmployeeTopBar, TopBar, Sidebar, EmployeeSidebar, MetricCard, LiveWorkforceTable, RecentActivity, login/hero sections, etc.) got dark: Tailwind variants added to their classNames.
Actual toggle buttons wired up: TopBar.jsx and EmployeeTopBar.jsx now have working sun/moon toggle buttons calling toggleTheme() (previously just a static Moon icon with no behavior).
2. Navigation fixes and wiring

Many buttons/icons that were previously non-functional (just styled <button>/<Link> elements) are now wired to useNavigate():

Notification bell, help icon, profile icon across almost every top bar now route to /notifications, /support, /profile.
Sidebar "Help Center" links now route properly.
Fixed a routing bug: several sidebar/topbar "Account"/"Employees"/"Directory" links pointed to the wrong route (/employee-dashboard or /profile) and were corrected to /profile or /employees as appropriate.
EmployeeProfilePage.jsx / Report.jsx — clicking the app title/logo now navigates to /dashboard.
Disabled/unfinished features are now explicitly marked with disabled + a title tooltip (e.g. "Editing employee records isn't available yet", "Calling isn't available in this demo") instead of silently doing nothing.
3. New functional features by page
Login (LoginForm.jsx): "Forgot Password?" is now a real working button calling authApi.forgotPassword(), with loading/status states — previously it was a dead link.
Employee Dashboard (EmployeeDashboardPage.jsx / AttendanceCalendar.jsx): Attendance calendar now supports prev/next month navigation, fetching a new month's data from the API on demand.
Leave Management (LeaveManagement.jsx): Added a working status filter dropdown (All/Pending/Approved/Rejected) that now actually filters the API query and CSV export.
Messages (MessagesPage.jsx):
In-conversation search (toggleable, filters messages by content).
Emoji picker for the message composer.
File attachment support (attach, preview, remove before sending).
Header cleaned up with call/video buttons now marked disabled/demo-only.
Notifications (NotificationsCenterPage.jsx):
"Quick Actions" panel is now interactive: an expandable notification preferences panel (email/push/attendance/leave/system alerts) backed by a real API, plus a CSV export of notification logs.
My Profile (MyProfilePage.jsx): Account settings buttons (change password, sign out) now navigate/act correctly.
4. Minor/misc
package-lock.json differs (dependency lock changes, e.g. "peer": true entries) — likely just from npm install after adding whatever new deps support these features (e.g. Checkbox component import in Notifications page).
General line-ending differences (old file uses CRLF, new uses LF) inflate the diff noise but aren't meaningful changes.
